Что такое iperf?  
Это консольная тулза для замера максимальной пропускной способности сети и диагноста сетевых соединений.  
В отличие от сервисов вроде Speedtest, которые меряют скорость до внешнего интернет-сервера, iperf  
позволяет тестировать скорость напрямую между двумя компьютерами или устройствами, например  
внутри нашей локальной сети, между сервером и клиентом, или между сервером и роутером.

Как установить на Windows?  
1) Заходим вот по этой ссылке: https://files.budman.xyz/  
2) Качаем последнюю версию, вирусов нет, можно проверить через virustotal.  
3) Распаковываем по пути: C:\iperf3  
4) Открываем Powershell от админа, переходим по пути: cd C:\iperf3  
5) Проверяем перед запуском, что всё ок: .\iperf3.exe --version  
6) Делаем один компьютер сервером: .\iperf3.exe -s  
На первом компе (который надо оттестировать), он поднимет миниатюрный сервер, на порту 5201.  
7) На втором компе запускаем .\perf3.exe -c [ip-шник первого компа]  
Где на втором компе будет располагаться iperf - без разницы.  
Всё, пойдёт тест соединения.  

Чтобы протестировать удалённый сервер в интернете, нужно чтобы на нём был  
установлен iperf, если iperf-a на нём нет, чуда не случится.

Как установить в разных Линухах?  

Ubuntu / Debian / Astra / Kali:  

sudo apt update  
sudo apt install iperf3 -y  

CentOS / RHEL / Rocky / AlmaLinux / Fedora:  

sudo dnf install iperf3 -y  

Arch Linux:  

sudo pacman -S iperf3  

ALT Linux:  

sudo apt-get update  
sudo apt-get install iperf3  
apt-cache search iperf3 // Проверка наличия пакета.  
________________________________________________________________________________________________________  

Проверить установку можно командой:  

iperf3 --version

Провести тест между двумя Linux-машинами можно так:  

На первой запускаем миниатюрный сервер:  

iperf3 -s  
sudo ufw allow 5201/tcp comment 'iperf3' // Чтобы сервер принимал подключения, нужно открыть порт в Firewall.  
sudo ufw status, или sudo ufw status verbose // Покажет список активных правил Firewall-a.  

На второй:  

iperf3 -c [IP-шник_ПЕРВОЙ_МАШИНЫ]  

Или более расширенная команда для клиента:  

iperf3 -c [IP-шник_ПЕРВОЙ_МАШИНЫ] -P 4 -t 10  

-P 4 // количество потоков, т.е. количество одновременных TCP-соединений,  
через которые одновременно передаются данные между клиентом и сервером.  

-t 10 // количество секунд, которое будет длиться тест.  

-R // передавать данные от сервера к клиенту. Т.е. запустить данные в реверс.
