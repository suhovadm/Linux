Что такое алиасы?  

В Линуксе алиасы (alias) - это сокращения для команд, которые позволяют заменить  
длинную команду коротким названием.  
________________________________________________________________________________  

1.  
Как сделать алиасы постоянными?  

Чтобы алиасы сохранялись после перезагрузки компьютера и повторного открытия  
терминала, нужно добавить их в файл конфигурации оболочки.  

Для BASH это вот так:  

nano ~/.bashrc  

И в конец файла скидываем все свои алиасы:  

My custom aliases  

Навигация:  
alias ..='cd ..'  
alias ...='cd ../..'  
alias home='cd~'  

Работа с файлами:  
alias ll='ls -lah'  
alias la='ls -A'  
alias l='ls -CF'  

Система:  
alias update='sudo apt update && sudo apt upgrade -y'  
alias cls='clear'  
alias hdd='df -h'  
alias mem='free -h'  
alias disk='lsblk'  

Сеть:  
alias ipinfo='ip -br addr'  
alias ports='ss -tulpn', или alias ss='ss -tulpn'  
alias myip='ip a'  

Процессы:  
alias processes='ps aux'  

Сохраняемся, выходим: Ctrl + X, Y, Enter.  
Затем применяем изменения: source ~/.bashrc  
Теперь алиасы будут доступны при следующих запусках BASH.  

* Если мы под ZSH, то вот так: nano ~/.zshrc  
* Сохраняемся: Ctrl + X, Y, Enter.  
* Применяем изменения: source ~/.zshrc  
________________________________________________________________________________  

2.  
Чтобы посмотреть все алиасы: alias  
Чтобы посмотреть конкретный: alias ll  
Чтобы удалить алиас: unalias ll  

Также, можно посмотреть что данная конкретная команда является алиасом.  
Это делается вот так:  

type ll  

На выходе будет что-то типа такого:  

ll is aliased to 'ls -lah'  
________________________________________________________________________________  

3.  
Чтобы удалить все алиасы текущей сессии: unalias -a  
Если алиас записан в .bashrc, то после перезапуска оболочки, он появится снова.  
________________________________________________________________________________  

4.  
Одинаково ли работают алиасы?  
Во всех популярных Линухах, типа Ubuntu / Debian / Kali / Mint / Fedora / Arch  
используются либо BASH, либо ZSH.  
* Синтаксис алиасов практических одинаков что BASH, что в ZSH!  

BASH:	           ~/.bashrc  
ZSH:	           ~/.zshrc  
FISH:	           ~/.config/fish/config.fish  
________________________________________________________________________________  

5.  
Как узнать какая оболочка используется?  

echo $SHELL, или echo $0
