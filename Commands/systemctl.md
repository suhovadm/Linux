Что такое systemctl ?  

Это консольная утилита в Линукс для упралвения системными службами (сервисами) через менеджер инициализации systemd.  
Проще говоря, systemctl позволяет управлять программами и службами, которые работают в фоновом режиме: запускать,  
останавливать, перезапускать и проверять их состояние.  

Что можно делать с помощью systemctl ?  

* Запускать и останавливать системные службы.  
* Перезапускать службы после изменения конфигурации.  
* Проверять, работает ли нужная служба.  
* Управлять автоматическим запуском служб при запуске системы.  

1. start - запустить службу.  
sudo systemctl start nginx  

2. stop - остановить службу.  
sudo systemctl stop nginx  

3. restart - перезапустить службу. Например, после изменения конфигурации.  
sudo systemctl restart nginx  

4. status - проверить состояние службы.  
Показывает информацию о службе:  
* запущена ли она;  
* работает ли без ошибок;  
* её идентификатор процесса (PID);  
* последние записи журнала.  

sudo systemctl status nginx

Самые интересные штуки:  

enable - включить автозапуск службы при запуске системы.  
disable - отключить автозапуск.  
reload - перезагрузить конфигу службы без полного перезапуска  
is-active - проверить, активна ли служба.  
is-enabled - проверить, включён ли автозапуск.  
_________________________________________________________________________________________________________________________  

* systemctl управляет именно службами, а не пользовательскими процессами!  

Например:  

nginx - веб-сервер;  
ssh - ssh-сервер;  
docker - docker;  
mysql - база данных.
