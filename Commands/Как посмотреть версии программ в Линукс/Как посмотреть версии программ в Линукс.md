Как посмотреть версию программы?  

Если у нас Debian/Ubuntu/Lubuntu и программа установлена через dpkg, то вот так:  

dpkg -l | grep google  
________________________________________________________________________________  

Если надо посмотреть версию конкретной программы, то лучше вот так:  

dpkg -s <имя пакета> | grep Version  

dpkg -s google-chrome-stable | grep Version  

dpkg -l google-chrome-stable  
________________________________________________________________________________  

Другие варианты:  

google-chrome --version  
python3 --version  
git --version  
docker --version  
nginx -v  

________________________________________________________________________________  

Если мы не знаем, каким пакетом установлена программа, найти её можно так:  

dpkg -l | grep -i google  

-l это маленькая L.
-i делает поиск без учёта регистра.
