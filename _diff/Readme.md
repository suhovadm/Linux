Что такое diff?  
Это консольная утилита в Линукс для построчного сравнения содержимого двух текстовых файлов и каталогов.  
Очень полезен, чтобы сравнивать конфиги ДО и ПОСЛЕ изменения.  

Обычно, он установлен по умолчанию во всех популярных Линуксах из коробки.  
Ubuntu / Kubuntu / Xubuntu / Lubuntu / Mint / Debian / Astra / Alt / Arch / openBSD / freeBSD  
__________________________________________________________________________________________________________  

Чтобы проверить, есть ли он вообще - вводим:  
diff --version  

Если его нет - устанавливаем.  

В Убунтах / Mint / Debian / Astra:  

sudo apt install diffutils  

В Альтушках:  

sudo apt-get install diffutils  

В Арче:  

sudo pacman -S diffutils  

В openBSD:  

doas pkg_add diffutils  

В freeBSD:  

sudo pkg install diffutils  
__________________________________________________________________________________________________________  

Основной синтаксис:  

diff [опции] файл1 файл2  

diff [опции] каталог1 каталог2  

Обычно, вводится без ключей, просто diff и два конфига:  
 
diff config_old.txt config_new.txt  
__________________________________________________________________________________________________________   

Ключи и команды.  

• -q (brief) — выводит только сообщение о том, различаются файлы или нет, без деталей.  
• -r (recursive) — рекурсивно сравнивает подкаталоги и файлы внутри папок.  
• -u (unified) — выводит различия в унифицированном формате (удобно для создания патчей).  
• -y (side-by-side) — показывает содержимое двух файлов в две параллельные колонки.  
• -i (ignore-case) — игнорирует регистр букв.  
• -w (ignore-all-space) — игнорирует любые пробелы и табуляцию.  
• -B (ignore-blank-lines) — игнорирует пустые строки.
